# GEXFI H5 收益宝 · V2 深色与付款增量版

本包基于 V1 H5 原型修改，不是现有 H5 源码的生产构建，不能覆盖线上客户端。

## 打开顺序
1. `START_HERE.html`：入口说明。
2. `GEXFI_H5_Income_Standalone.html`：单文件全功能原型，图片和中英文PDF均已内嵌。
3. `prototype/h5-income.html`：与单文件相同的模块化资源版。
4. `integration/README_IT_CN.md`：接入范围及付款业务说明。

## 本版新增
- 所有新增收益页面和弹层改为现有 H5 深色体系；不改原页布局和四个底部菜单。
- 申购金额页增加“USDT余额 / 法币购买USDT”选择。
- 全额法币购 U：先显示 USDT 到账数量、CNY 应付总额、含价差成交报价，再创建付款订单。
- 扫码 / 同手机打开收银台 / 待付款 / 查询 / 请求取消 / 超时 / 付款返回 / 到账审核 / 购 U 执行 / 入账。
- 购 U 结算后另行确认收益宝条款；不自动投资、不以扫码等同到账。
- 取消途中收到付款、金额不符、未成交退款、迟到款退款等异常分支。
- 首期外部转入 USDT 仍不能直接申购。已有受理、持仓、到期、转卡、Memo功能保留。

## 演示方法
打开手机右上角“场景切换”，或桌面手机上方“演示控制”。
选择“首次购 U · 无余额”，依次操作：申购金额 → 法币购U → 勾选报价 → 创建模拟付款订单。
随后用演示控制逐步切换：付款返回 → 收款确认 → 财务放行 → 购U入账。
点击“继续，确认收益宝申购”，主动勾选产品文件与风险，再提交并模拟受理。

## 支付渠道边界
截图只证明订阅卡充值收银台的交互，不证明同一商户号可用于购 U。
当前原型里的支付宝和微信购 U 选项不可用；仅 Demo Checkout 可操作。
二维码内容为非支付文本，没有真实收款地址、二维码、链接或商户号。
生产时由后端按实际地区、交易用途、渠道规则及准入决定返回支付方式；无可用方式则不收款。
不得改写为“AI订阅”“软件服务”或“卡充值”以替代真实购U交易用途。
